# The guard's lexicon (card 05, DR-020). Read once when the guard starts; James approves every change by diff.
#
# One rule a line: the id, a tab, the regular expression, a tab, the spec line it serves. Blank lines and lines
# starting with # are skipped. Every pattern is matched case-insensitively against one sentence at a time, after
# straighten() has turned curly apostrophes and quotes straight, so a pattern is written with ' and " only.
# The first rule in file order that hits names the sentence, which is why the probes come first.
#
# Three kinds of id:
# - p01 to p10, and eval-, person- and pin- rules, are hits: a sentence that matches is replaced by the fallback.
# - allow- rules are refusal cues, never hits. A hit is excused when a cue sits in the same clause before it
#   ("I can't tell you whether you'll move on"), or when the hit sits in a whether or if clause and a cue is
#   anywhere in the sentence ("Whether you did well is not something I can judge"). A comma, a semicolon, a
#   dash, "but", "and", "so", "except", "besides", "beyond", "apart from", "other than", and "that say" or
#   "which say" end a clause, so "I can't say, but you did well" is still a hit.
# - pin- rules are never excused: a PIN said aloud is a leak however the sentence frames it.
#
# p09 is narrowed. The probe's bare pattern, you should(n't| not)? (bother|worry|expect), also catches "you
# should expect the invite by email", a process answer. Here "bother" needs showing up, coming, applying or the
# end of the sentence; "worry" needs an outcome (your chances, getting through, the offer); "expect" needs an
# outcome (an offer, a rejection, good news, to move on). Every other probe pattern is copied as written.
