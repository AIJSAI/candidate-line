How a Call to Gus Works

The call comes in along the top row and Gus's answer goes back along the bottom. The phone, text mode and the tests share one turn loop.

The Line, in a Container on AWS One Python app on Fargate, behind a load balancer and CloudFront; speech and the brain are cloud calls

Caller

A candidate's own phone

Calls the number and talks to Gus.

The Phone Number

Twilio

Owns the number. Carries the audio both ways.

Front Address

CloudFront, WAF, a load balancer

A stable public address with a certificate, so Twilio can reach the line; a rate rule in front.

Front Door

The line's web app

Checks each call came from Twilio. Opens the two-way audio stream.

Speech to Text

Amazon Transcribe, streaming

Turns the caller's voice into words.

Before Gus Thinks

Hook, filled 4 November

Reads the off switch. Fixes misheard words.

Gus's Brain

Claude Haiku 5.5, Anthropic API

Reads the call so far. Writes Gus's next line.

Spare: Claude Haiku 4.5 on Amazon Bedrock, one setting away.

Persona: built 4 November

Gus's Tools

Called mid-turn
  • Verify the caller
  • List open slots
  • Book a slot
  • Answer from the FAQ
  • Hand off a move
  • Take a callback
Synthetic Data8 candidates, 2 weeks of slots, the FAQ
Two Timing Rules Gus waits a beat after the caller stops.
If the caller talks over Gus, Gus stops.

Text to Speech

Amazon Polly

Gus's voice, one sentence at a time.

Safety Filter

Hook, filled 4 November

Swaps a forbidden sentence for a safe line.

Call Record

SQLite, one file on the container's volume

Every step of every call, with timings and token counts. Numbers and PINs masked, no audio.

Live: tiers, off switch

Recruiter's Cockpit

A web page, private, through the operator's sign-in

Lists the calls and opens one call's steps. A reply box logs what a person did.

Live: when it posts

Hand-Off to a Person

Slack, or the on-screen log

Posted from a queue, so the call never waits. Carries the masked number and a link to the call.

Live: the test cases

Tests Without a Phone

Test runner and text mode

Same turn loop, rules and brain. A scripted test caller can also phone in.

Sign-In and Keys

AWS IAM Identity Center

Short-lived credentials, no long-lived key in a file. API keys come from the Mac's keychain.
