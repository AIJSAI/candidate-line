# Architecture page: where each box comes from

The page is `architecture.html` beside this file, drawn from this repository at commit 3919773 on 2026-11-03 (the cockpit's pages restyled in that commit; line numbers in this file are as of that commit, and a few lines moved on main afterwards, so open a file at that commit to match them exactly) and relaid on the same evening (titles in Title Case, one caption and at most two lines per box, a "Two Timing Rules" callout, a "Live" pill on a pre-built box whose live part is named after the colon). On 2026-11-05 the band "The Outbound Call" was added below the call, with a blue swatch in the legend, a sentence at the end of the subtitle and the footer, and the footer's date; its rows below cite commit 5a82634, the head of the outbound build. Each box below names the code or record that proves it. Paths are relative to that repository.

## Top row: the call coming in

- **Caller; The Phone Number (Twilio).** Twilio owns the number and calls the line's `/voice` webhook: `candidate_line/telephony/app.py:123-143`. The answer tells Twilio to open a two-way audio stream: `app.py:55-61`. Record: DR-005.
- **Front Address (CloudFront, WAF, a load balancer).** Since the evening of 4 November the line runs in a container on AWS: `infra/aws/candidate-line-stack.yaml` (the distribution, the web ACL, the load balancer open only to CloudFront's addresses), record DR-023. Before that it ran on a Mac behind a quick tunnel (`scripts/up.sh`, DR-005), which the page showed until this row was rewritten.
- **Front Door.** The signature check that proves a request came from Twilio: `app.py:41-45` and `app.py:126-132`. The audio WebSocket: `app.py:145-190`.
- **Speech to Text (Amazon Transcribe, streaming).** `candidate_line/telephony/speech.py:84-161`, `start_stream_transcription` at `speech.py:109`; built per call at `app.py:84`.
- **Two Timing Rules, first line (Gus waits a beat after the caller stops).** The grace window and the superseded turn: `candidate_line/telephony/media.py:36-46`. Record: DR-006.
- **Two Timing Rules, second line (if the caller talks over Gus, Gus stops).** Barge-in sends Twilio a `clear`: `media.py:316-322`, triggered at `media.py:190-191`.
- **Before Gus Thinks (live; "reads the off switch, fixes misheard words").** The `on_turn` hook: `candidate_line/hooks.py:19-20`, empty in `LineHooks` at `hooks.py:62-63`. Card 04 fills it with the misheard-word fixes (`prompts/04-tools-and-persona.md:15`), card 06 with the kill switch (`prompts/06-tiers-and-observer.md:8`).
- **Gus's Brain.** One turn: `candidate_line/turn.py:59-77`, called by the phone at `media.py:251`. The provider switch: `candidate_line/brain/provider.py:295-301`. Haiku 5.5 on the Anthropic API is the default: `candidate_line/settings.py:49` and `settings.py:65`. The Bedrock spare, Haiku 4.5: `settings.py:64`, `provider.py:109-170`. Record: DR-003.
- **Call Record and Recruiter's Cockpit captions.** The store is one SQLite file on the container's volume (EFS, DR-023) and the cockpit runs on the container's loopback, reached through the operator's SSM port-forward (`make cockpit-forward`).
- **Persona (the tag inside Gus's Brain).** Built the evening of 4 November: `candidate_line/persona.py` holds the brief, the fixed lines and the FAQ index. Record: DR-019.
- **Gus's Tools (live; the six list items are the six tool names, in plain words: Verify the caller, List open slots, Book a slot, Answer from the FAQ, Hand off a move, Take a callback).** Built the evening of 4 November: `candidate_line/tools/actions.py` holds the six tools plus `end_call`, and the loop in `candidate_line/turn.py` runs them (DR-019); the brain's tool channel is `provider.py:21-46`. The six tool names come from `prompts/02-eval-cases.md:17`: verify_caller, list_open_slots, book_slot, move_slot, answer_question, request_callback. At one hour a move is a hand-off to the coordinator (the session's run plan (not in this tree), "At 60").
- **Synthetic Data (the inner box).** `data/candidates.yaml` (8 candidates), `data/slots.yaml`, `data/faq.md`. Record: DR-009; `PREBUILT.md` row 6.

## The outbound band: the line calls an applicant (built 5 November)

Spec section 9, record `docs/decisions/DR-025-outbound-screening.md`, work item `prompts/08-outbound-screening.md`. Line references at commit 5a82634. These rows cite the code and its tests; no live call of the outbound path is recorded here, and that evidence goes into DR-025.

- **The band's label.** "Off by default": `OUTBOUND_ENABLED` reads 0 unless set, and anything but 0 or 1 stops the process at start (`candidate_line/settings.py:234-236`); the stack's `OutboundEnabled` parameter defaults to "0" (`infra/aws/candidate-line-stack.yaml:28-31`). "The same front door, stream, brain and guard": one `/voice` route answers both directions (`candidate_line/telephony/app.py:407-408`), the media session takes the outbound seed from the dial record (`candidate_line/telephony/media.py:128-151`), and the turn loop runs with `OUTBOUND_TOOL_SPECS` (`candidate_line/tools/actions.py:687`), which adds `confirm_applicant`, `record_answer` and `stop_calls` (`candidate_line/tools/screening.py:301`, `:352`, `:450`) to the tools; the Gus's Tools box still lists the six inbound tools. "Applicants listed in the cockpit": `GET /applicants` and `GET /applicants/{code}` (`candidate_line/traces/cockpit.py:621-630`), in arrival order with no sort, filter, colour or count by answer (`cockpit.py:1-12`, DR-025 section 16). "Three new secrets in Secrets Manager": INTAKE_SIGNING_KEY, OUTBOUND_ALLOWED_NUMBERS and TWILIO_LINE_NUMBER as the task's secret references (`infra/aws/candidate-line-stack.yaml:305-307`), stored from the keychain by `scripts/deploy.sh:47-58`. "A person makes every hiring decision": spec section 5, Never 1 and Never 7.
- **Signed Intake (POST /applications).** Mounted at `candidate_line/outbound/intake.py:147`; the HMAC-SHA256 over the timestamp, the nonce and the body is compared in constant time at `intake.py:165`, and a nonce seen in the last ten minutes is refused with 409 at `intake.py:170`. An application with no consent, from an opted-out number or from a number off the allow-list is stored with its reason and never dialled (`intake.py:210`); otherwise the first dial is scheduled (`intake.py:236`). The careers form is not in this repository; `make apply` signs a synthetic application for a walk (`scripts/deploy.sh:107-136`). Spec 9.1, DR-025 section 10.
- **Contacts Store.** The one store of raw numbers, read only by the dialler: `candidate_line/outbound/contacts.py:1-8`; mode 600 at `contacts.py:30`; `purge` at `contacts.py:111` and `delete` at `contacts.py:102`. The 30 days are `DEFAULT_CONTACTS_RETENTION_DAYS` (`candidate_line/settings.py:39`), swept on every dialler tick (`candidate_line/outbound/dialler.py:173`); a number that opted out is deleted within one tick (`dialler.py:196-206`). A deletion request (`make forget CODE=`) removes it too. Spec 9.13, DR-025 section 9.
- **Dialler.** One loop in the line's process, every 15 seconds (`dialler.py:42`, `dialler.py:139-145`). `closed` refuses every dial with dialling off, the kill or no-dial file set, or the task under 120 s old (`dialler.py:208-220`); the window is read per applicant's zone (`dialler.py:222-226`, `candidate_line/outbound/window.py:37`); the day's cap is passed to the claim (`dialler.py:160-163`); the allow-list is checked as an exact string immediately before the dial (`dialler.py:253-258`) and again when `/voice` answers (`dialler.py:398-410`). The defaults: 09:00 to 20:00 Monday to Saturday, never Sunday (`settings.py:42`, `settings.py:88`), 3 attempts and 20 dials a day (`settings.py:37-38`). The voicemail on the first attempt only and one call at a time are spec 9.3 to 9.5. `make dial-off` and `make dial-on` set and clear the dialler's own stop (`scripts/deploy.sh:90-93`).
- **Twilio Dials Out (opening in Twilio's own voice).** The answered outbound call is `<Say>` with the opening before `<Connect><Stream>` (`candidate_line/telephony/app.py:113-124`), so no barge-in can cut it; the opening's words are `OUTBOUND_OPENING` (`candidate_line/persona.py:38`), and the stream's first line is the PIN ask (`persona.py:42`). Spec section 5, Never 3, and 9.6.
- **The Gate, in Code (before book_slot).** One pure function, `rules.check` (`candidate_line/tools/rules.py:50`), with `meets` for one answer against one posted rule (`rules.py:27`); `list_open_slots` and `book_slot` refuse an applicant until the gate says every question was asked and every requirement met (`candidate_line/tools/actions.py:329`, `actions.py:421`, the refusals at `screening.py:72-73`), and the ledger refuses the booking again (`candidate_line/tools/ledger.py:1363`). It is never spoken as a judgment: every line after an answer is a fixed line of spec 9.9, said by code (`screening.py:1-10`). Spec 9.10.
- **Book or Hand Off (screening hand-off by email).** Met with open slots: up to three of the role's recruiter's open times, read by code (`persona.py:60`, `MET_LINE`), and a booking when the applicant names one. Not met, or met with no open slot: the not-met or no-slot line (`persona.py:64-71`, `NO_SLOT_LINE` and `NOT_MET_LINE`) and a tier-2 screening hand-off (`screening.py:242`). The email (`candidate_line/escalation.py:111-130`) names the applicant, the role, the promised time and the record link, and never an answer; it goes through SES to the configured recipients, which on the stack at this commit are the operator's address (`infra/aws/candidate-line-stack.yaml:287-288`). Spec 9.11, DR-025 section 15.

## Built before the session, and planned for it

From `PREBUILT.md`: rows 1 to 12 and the list after the tag are pre-built; its last section lists what is built live (the spec, the cases, tracing, the tools and the persona, the guard, the tiers and the hand-off rule, the kill switch and the override log, the scorecard). At one hour, the session's run plan (not in this tree) lands card 06 (the tiers, the hand-off rule and the kill switch) only if card 05 is green by minute 50; otherwise it is described, so those three dashed parts may be said rather than shown.

- **Why the captions read this way.** "Before Gus Thinks" and "Safety Filter" carry the caption "Hook, filled live": the four hooks are pre-built shells (`PREBUILT.md` row 5, `candidate_line/hooks.py`) and only their bodies are built live (cards 04 and 05), so the orange box names the live part. The "Two Timing Rules" callout takes the grey fill because both rules are pre-built (`PREBUILT.md` row 3; `candidate_line/telephony/media.py:36-46` the grace window, `:316-322` the clear on barge-in). The footer makes card 06 conditional on the clock, as the session's run plan (not in this tree) "At 60" says.
- **Why the outbound band is blue.** It was built on 5 November, the day after the orange boxes, from its own card (`prompts/08`) and record (DR-025), so it takes its own swatch in the legend rather than the orange of 4 November. It sits under the call because it runs through the same front door, stream, brain and guard, and it adds no box to the call itself.
