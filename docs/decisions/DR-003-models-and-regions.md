## What it is

Which model does which job on the line, in which region, through which id, and what the first call from the CLI showed.

## The decision

- **The live turn: Claude Haiku 5.5 on the Anthropic API** (decided 2026-11-02 13:10 CT, below), because this account's Bedrock quota for the 5.5 models is zero; Haiku 4.5 on Bedrock (`us.anthropic.claude-haiku-4-5-20251001-v1:0`) is the fallback.
- **The callback summary nobody waits on: Claude Sonnet 5.5**, `us.anthropic.claude-sonnet-5-5`, same routing. Confirmed present in us-east-1 on 2026-11-01, which closed the open check.
- **The speech-to-speech arm: Amazon Nova 2.5 Sonic**, `amazon.nova-2-5-sonic`, In-Region only, on demand in us-east-1; us-west-2 is the spare region. Its agreement was already AVAILABLE in this account on 2026-11-01 with nothing to accept.
- **Speech out for arm A: Polly**, which emits `mulaw` at 8000 Hz directly, the format the Twilio stream wants, so no codec sits between Polly and the phone (Polly API reference, read 2026-11-01).
- **Thinking on the live turn: off, effort low.** Haiku 5.5 thinks by default with effort medium; the card says thinking can be turned off and effort set from low to max, capped at high when thinking is off. Measured 2026-11-02 (Evidence): with adaptive thinking on and a 120-token cap, three of five Gus-sized replies came back with no text because the thinking spent the budget, which on a phone line is a silent Gus. The brain's `LOW_LATENCY_REQUEST` is the recorded setting.
- **Model access** is enabled on first invoke when the caller holds the three AWS Marketplace actions; the two Claude models also need Anthropic's one-time use-case form and a Marketplace agreement each, submitted from the CLI with `put-use-case-for-model-access` and `create-foundation-model-agreement`. Those two are consent actions and James runs them himself; the form's text is `infra/aws/anthropic-use-case-form.json`.

## The alternative rejected, and why

- **Sonnet 5.5 on the live turn.** The caller is waiting; Haiku 5.5 is the latency model, and the summary is the only job where quality per token beats time.
- **Opus 5.5 anywhere on the line.** Present in us-east-1, never needed: nothing on the line is a hard reasoning task.
- **Nova 2 Sonic.** Its end of life is no sooner than Dec 2, 2026 (DR-001), inside the first months of use; the 2.5 model is the one measured.
- **An In-Region Claude endpoint.** None exists for the 5.5 models; the geo profile is the only path, so "which region" means "which routing set".
- **Converting Polly PCM to mu-law in Python.** Unnecessary once the API shows `mulaw` as an output format; one fewer place to get audio wrong.

## Re-examined 2026-11-04 evening: the brain stays on the Anthropic API

- **Claude Haiku 4.5 on Bedrock passes the boundary cases but not this account's request quota.** The eval set of DR-017 was run on `us.anthropic.claude-haiku-4-5-20251001-v1:0` twice (17:50 and 17:54 CT, `BRAIN_PROVIDER=bedrock`, an in-memory ledger, a scratch trace store). **Decision, re-affirmed 2026-11-04 about 18:05 CT:** the live brain stays Claude Haiku 5.5 on the Anthropic API; Bedrock stays the one-switch spare with Haiku 4.5. The brain moves to Bedrock when either of two things changes: a Claude 5.5 quota opens on this account, or the Haiku 4.5 request quota reaches a rate that covers a call (about 20 a minute) and a full eval run on it passes every boundary case that Haiku 5.5 passes, which was the condition set that evening. The résumé line and the records say "with Claude on Bedrock one setting away", never "on Bedrock".

**The spare's retries, split the same evening after review:** a live call's Bedrock client makes two attempts in all (one retry) with a 10 s read bound, so a throttle costs one retry and then the recovery line rather than seconds of silence; the eval runner's client makes seven, since nobody waits on an eval turn (`make_brain(settings, max_attempts=7)` in `candidate_line/evals/runner.py`). DR-001's 2,000 ms budget does not cover a throttled turn on the spare at all.

## Re-examined 2026-11-05: there is no temperature to set

Card 08's eval step saw one different case flake on each of five full runs of 52 (CL-039, CL-044, CL-057, CL-034, CL-055, CL-005): a reply the brief forbids, said one time in several, such as a callback turn that asks for a time first or a verify turn that names neither the code nor the PIN. The first instinct, temperature 0, is not available: the Anthropic SDK the line runs (2.3.0) takes no sampling parameter on `messages.create` (its parameters are the model, the messages, the system, the tools, thinking, output_config, speed and service_tier), and the request was refused with a TypeError on the eval step's sixth run. So the variance is the model's own, and the levers are the ones the day used: a fixed line said by code where the words must be the same every time (the move request, the screening lines, the PIN cue), a brief rule that names the words, and a case bar that reads a refusal as the guard does. The spare on Bedrock takes a temperature in its inferenceConfig, but a setting one provider honours and the other cannot would make the drill a different line, so neither sends one.
